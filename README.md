# DIC-1 · Personal Page

My personal page for the **Internet of Things (IoT) Data Analysis and Applications** course — assignment **DIC-1**.

Built with plain **HTML, CSS, and JavaScript** (no framework). Features a live
clock, a time-of-day greeting, and a 12H / 24H toggle.

## 🔗 Links

- **Live site:** https://mumumush.github.io/DIC1_PersonalPage/
- **Repository:** https://github.com/mumumush/DIC1_PersonalPage

> The live link works once GitHub Pages is enabled (Settings → Pages → Branch `main`, folder `/root`).
